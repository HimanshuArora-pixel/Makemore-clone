# makemore

A from-scratch progression of character-level name generators, built while following Andrej Karpathy's "Neural Networks: Zero to Hero" series. Each notebook builds on the last, moving from a simple bigram lookup table to a WaveNet-style hierarchical CNN, with a full manual backpropagation implementation along the way.

All models are trained on `names.txt`, a list of ~32K English names, and generate new, name-like strings one character at a time.

## Contents

| # | Notebook | Model |
|---|----------|-------|
| 1 | `bigram.ipynb` | Bigram frequency table + single-layer neural net |
| 2 | `MLP.ipynb` | Multi-layer perceptron with learned character embeddings |
| 3 | `MLP2.ipynb` | MLP + BatchNorm, train/dev/test split, hyperparameter tuning |
| 4 | `MLP_with_backprop_scratch.ipynb` | Same MLP, backpropagation derived and implemented manually (no `.backward()`) |
| 5 | `wavenet.ipynb` | WaveNet-style hierarchical architecture with dilated context fusion |

## 1. Bigram Model (`bigram.ipynb`)

The starting point. Builds a 27x27 count matrix (26 letters + `.` as start/end token) over all adjacent character pairs in the dataset, converts it to a probability table with add-1 smoothing, and samples from it directly.

The same bigram statistics are then reproduced using a single linear layer trained with gradient descent on the negative log-likelihood loss, showing the equivalence between a counting-based model and a 1-layer neural net.

- Input: one-hot encoded single character
- Output: probability distribution over the next character
- Loss: negative log-likelihood, converges to ~2.45

## 2. MLP (`MLP.ipynb`)

Implements the Bengio et al. neural probabilistic language model. Characters are mapped to learned embedding vectors, several are concatenated as context, and passed through a hidden `tanh` layer to a softmax output.

- Learned character embedding table `C`
- Configurable context window (`block_size`)
- Trained with minibatch gradient descent
- Train/dev/test loss evaluated separately

## 3. MLP2 (`MLP2.ipynb`)

Same architecture as above, refined with the training diagnostics from Karpathy's "Building makemore Part 3." Includes:

- BatchNorm applied to the hidden layer pre-activation, with running mean/std tracked for inference
- Careful initialization scaling (`W1`, `W2` scaled down) to fix the initial loss and keep `tanh` activations from saturating
- Removal of the redundant bias term made unnecessary by BatchNorm
- Loss curve visualization over 200,000 training steps

## 4. MLP with Manual Backprop (`MLP_with_backprop_scratch.ipynb`)

The same MLP + BatchNorm model, but every gradient is derived and computed by hand instead of calling `loss.backward()`. Covers manual backprop through:

- Cross-entropy / softmax
- BatchNorm (mean, variance, normalization, gain, bias)
- The linear and `tanh` layers
- The embedding lookup

Each manual gradient is checked against PyTorch's autograd output using an exact-match and approximate-match comparison (`cmp()` helper), confirming correctness node by node through the computational graph.

## 5. WaveNet (`wavenet.ipynb`)

Extends the context window from 3 characters to 8 and replaces the flat concatenation of embeddings with a hierarchical, WaveNet-inspired fusion:

- 8 characters -> 4 groups of 2 -> 2 groups of 2 -> 1 group, progressively merging adjacent pairs instead of flattening everything at once
- Implemented as a custom `Layer`/model stack built on `torch.nn` modules, moved to GPU (`device`)
- Trained with `torch.optim.SGD` and a step learning-rate scheduler (200,000 steps, decaying at 95k/190k)
- Includes a check for how many generated names are novel (not present in the training set)

## Usage

Each notebook is self-contained. Place `names.txt` in the same directory and run top to bottom:

```bash
jupyter lab
```

Open the desired notebook and run all cells. The final cells in each notebook sample new names from the trained model.
